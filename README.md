# Comparative Bioinformatics Analysis of Insulin Protein Sequences Across Selected Mammalian Species

## Project Overview
This project investigates the similarities and differences in insulin protein sequences across ten selected mammalian species using bioinformatics tools.

## Objectives
- Collect insulin protein sequences from selected mammalian species.
- Perform multiple sequence alignment.
- Identify conserved and variable sites.
- Analyze pairwise evolutionary distances.
- Construct Neighbor-Joining (NJ) and Maximum Likelihood (ML) phylogenetic trees.
- Analyze physicochemical properties and amino acid composition.

## Tools Used
- NCBI Protein Database
- ExPASy ProtParam
- MEGA
- R and RStudio
- Microsoft Excel

## Species
Human, chimpanzee, rhesus macaque, mouse, rat, cow, pig, horse, dog, and rabbit.
